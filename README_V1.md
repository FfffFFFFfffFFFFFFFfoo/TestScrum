# Yandex Music Backup

Инструмент для резервного копирования и восстановления музыкальной библиотеки Яндекс Музыки.

## Возможности

Проект предназначен для сохранения музыкальной библиотеки пользователя и защиты её истории от изменений на стороне сервиса.

Планируемые возможности:

- **Сохранение треков и их версий** — хранение музыкальных композиций и связанных с ними данных: исполнителей, альбомов и другой информации.
- **Сохранение структуры библиотеки** — хранение плейлистов и списка понравившихся треков.
- **Резервное копирование** — обновление локальной копии библиотеки при запуске бэкапа.
- **История изменений** — просмотр состояния музыкальной библиотеки на моменты, когда выполнялись резервные копирования.
- **Восстановление** — возможность восстановить библиотеку до выбранного состояния.
- **Снимки (snapshots)** — создание полных контрольных состояний библиотеки.
- **Планирование резервного копирования** — автоматический запуск бэкапов по расписанию.

## Хранение истории

Для оптимизации использования памяти и скорости восстановления планируется гибридный подход:

- изменения библиотеки сохраняются в виде событий, а не отдельных полных копий;
- пользователь может создавать полные снимки (snapshots);
- при восстановлении выбирается подходящий способ получения требуемого состояния: применение изменений с начала истории, откат от текущего состояния или восстановление от снимка.

Это позволяет просматривать историю библиотеки и восстанавливать её состояние на момент ранее выполненного резервного копирования.

## Интерфейс

Первоначально взаимодействие с приложением будет осуществляться через CLI.

Архитектура проекта предусматривает возможность добавления других способов взаимодействия без необходимости перестраивать основную логику приложения.
