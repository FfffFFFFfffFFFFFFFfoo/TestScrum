# Yandex Music Backup

Инструмент для резервного копирования музыкальной библиотеки Яндекс Музыки, сохранения истории её изменений и восстановления предыдущих состояний.

## Текущее состояние

**В разработке.**

Проект находится на начальном этапе. В первых итерациях определяются архитектура, структура приложения и реализуются базовые компоненты.

## Интерфейс

Первоначальный интерфейс приложения — CLI (Command-Line Interface).

Архитектура предусматривает возможность добавления других способов взаимодействия с приложением без необходимости переносить в них основную бизнес-логику.
